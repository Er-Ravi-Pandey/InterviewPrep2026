Java 9 Topics (High Priority)
1. Module System (JPMS)

Most frequently asked Java 9 topic.

Concept:

Before Java 9:

jar -> classpath

After Java 9:

module -> requires -> exports

Example:

module com.bank.payment {
    requires java.sql;
    exports com.bank.service;
}

Interview Question:

Why was the Module System introduced?

Answer:

Better encapsulation
Faster startup
Smaller runtime images
Dependency management
2. Factory Methods for Collections

Java 8:

List<String> list = Arrays.asList("A","B");

Java 9:

List<String> list = List.of("A","B");

Similarly:

Set.of()
Map.of()

Questions:

Is List.of mutable?

Answer:

No. Immutable collection.

3. Optional Enhancements

Java 8:

Optional<String> name;

Java 9 added:

ifPresentOrElse()
or()
stream()

Example:

optional.ifPresentOrElse(
    System.out::println,
    () -> System.out.println("No Value")
);
4. Stream API Enhancements

Java 9:

takeWhile()
dropWhile()
ofNullable()

Example:

list.stream()
    .takeWhile(x -> x < 5)

Common interview question.

Java 10 (Quick Read)

Mostly one feature.

var Keyword
var name = "Ravi";

Compiler infers type.

Question:

Is Java dynamically typed now?

Answer:

No.

Still statically typed.

2. Files Utility Methods

Read file:

String content =
Files.readString(path);

Write file:

Files.writeString(path, content);

Common interview question.

3. Predicate.not()

Before:

list.stream()
    .filter(s -> !s.isEmpty())

Java 11:

list.stream()
    .filter(Predicate.not(String::isEmpty))
4. HTTP Client API

Big Java 11 feature.

Before:

HttpURLConnection

Java 11:

HttpClient

Example:

HttpClient client =
    HttpClient.newHttpClient();

Send request:

HttpRequest request =
    HttpRequest.newBuilder()
        .uri(URI.create(url))
        .build();

Interview Question:

What replaced HttpURLConnection?

Answer:

Java 11 HttpClient.
